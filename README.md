Kin brings connection controls, account information and live data usage into one compact interface, with light, dark and system themes. Accounts that offer locations can browse countries, cities and servers while connected.

## Get started

Published versions are available in [Releases](https://github.com/ozimellow/kin-clinet/releases).

Download the Windows ZIP, extract the complete folder and open **kin-clinet.exe**. Complete the one-time setup, add your connection token and select **Connect**.

For Android, download the **ARM64 APK** from [v0.0.5-dev.2](https://github.com/ozimellow/kin-clinet/releases/tag/v0.0.5-dev.2) and follow Android's installation prompts. This preview requires Android 10 or later; physical phone compatibility is still being validated.

## Updates

On Windows, use **Settings > About** to choose **Stable** or **Development**, then select **Check now**. Stable offers stable releases; Development also offers newer previews and receives stable promotions. Kin can download, verify and install an update in place with **Update and restart**. Your saved account is kept. In v0.0.5-dev.2, selecting Stable from a preview can also offer **Return to Stable** when the stable version is older.

The [v0.0.5-dev.2 development preview](https://github.com/ozimellow/kin-clinet/releases/tag/v0.0.5-dev.2) includes Windows x64 and Android ARM64 together. See its testing notes before installing.

The current stable release is [v0.0.4](https://github.com/ozimellow/kin-clinet/releases/tag/v0.0.4) for Windows x64. [Development releases](https://github.com/ozimellow/kin-clinet/releases) are available separately.

Starting with v0.0.5-dev.1, Android can check, download and verify its APK in **Settings > About**, then opens Android's installer for your approval. Install this first update from the older Android preview manually. Android Stable begins with the planned v0.0.5 release; no compatible Android Stable package is available yet.

On Windows, to remove Kin and its saved data, choose **Settings > About > Uninstall Kin**.
