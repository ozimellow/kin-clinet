# Kin client v0.0.4-dev.5

Android preview for ARM64 phones running Android 10 or later.

- Add and manage your saved connection.
- View account usage and connection activity.
- Browse countries, cities and servers when locations are available.
- Choose light, dark or system appearance.

Download the APK and complete Android’s installation prompts. Android updates currently require installing the newer signed APK manually. Physical phone compatibility is still being validated.

Windows v0.0.4 remains the stable Windows download.
