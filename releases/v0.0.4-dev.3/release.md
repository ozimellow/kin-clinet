# Kin client v0.0.4-dev.3

Windows x64 development preview.

- Reconnect with your last available server, or automatically choose one for a new connection.
- Display the confirmed server name and flag consistently.
- Smooth server-switching feedback, with reduced-motion support.
- Corrected text encoding in location navigation, server details and status labels.

To update in Kin, choose Settings > About > Development > Check now. Saved accounts and settings are preserved. Windows may request administrator approval.
