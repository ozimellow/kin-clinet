# Kin client 0.0.4-dev.1

Development preview for Windows x64.

- Fixed an issue where Retry cleanup could immediately return to the same warning.
- Improved settings icon spacing and text alignment.
- Fixed the clipped Development option in the update-channel menu.
- Replaced the line below focused buttons with an inset keyboard-focus outline.

To update from Kin, open Settings > About, choose Development, then select Check now and Update and restart. Your saved account is kept. Windows may ask you to approve the update.

For a first installation, download the Windows ZIP, extract the complete folder and open kin-clinet.exe.
