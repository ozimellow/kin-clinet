# Kin client v0.0.5-dev.1

Development preview for Windows x64 and Android ARM64. Both downloads belong to this release.

- Refined account, connection and update screens.
- Account names are displayed without the connection-label prefix.
- Automatic recovery after interrupted connections and optional connection protection.
- In-app update notifications, platform-specific downloads and required-update handling.

## Testing notes

Repeated interruption/recovery, DNS and web checks passed. This is a development preview for testing; the extended lifecycle and physical Android qualification remain in progress.

Windows: download and extract the ZIP, then open Kin. Existing stable installations can select Development in Settings to discover this preview.

Android: download and install the signed ARM64 APK using Android's installation prompts. The previous Android preview requires this first update to be installed manually.

Private test builds already displaying 0.0.5-dev.1 have the same version number; install these reviewed downloads manually to ensure the exact released build is present.

Windows v0.0.4 remains the stable release.
