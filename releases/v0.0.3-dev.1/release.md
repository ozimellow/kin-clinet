# Kin client 0.0.3-dev.1

Development preview for Windows x64.

- Browse available locations by country, city and server on supported accounts.
- Improved connection recovery and server-list refresh.
- Choose Stable or Development updates in Settings > About.
- Development also receives newer stable releases, including preview promotions.
- Install verified updates in place with Update and restart.
- Refined account information, connection status and update controls.

Download the Windows ZIP, extract the complete folder and open kin-clinet.exe. Your existing saved account is kept when upgrading.
