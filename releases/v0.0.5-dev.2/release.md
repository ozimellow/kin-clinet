# Kin client v0.0.5-dev.2

Development preview for Windows x64 and Android ARM64 phones, under one release tag.

- Windows: selecting Stable can now offer **Return to Stable**, even when the current Stable version is older than the installed preview.
- Channel changes retain package verification and required security-version checks.
- Android: updated channel-return handling and installation numbering for future Stable recovery packages.

Windows can return to v0.0.4 Stable through Settings. Android does not yet have a published Stable package; its first Stable release is planned as v0.0.5. Until then, selecting Stable reports that no compatible package is available.

Existing v0.0.5-dev.1 users can select Development and check for updates. The older Android v0.0.4-dev.5 preview requires manual APK installation for its first upgrade.

Android: use the ARM64 APK on an Android 10 or newer phone. No x64 emulator package is included.

This is a Development preview. Physical-phone acceptance and extended lifecycle qualification remain in progress. Windows v0.0.4 remains Stable.
