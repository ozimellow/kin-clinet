# Kin client v0.0.4-dev.4

Windows x64 development preview.

- Keep server selection visible when a group has one server or is temporarily empty.
- Refresh available locations automatically while connected.
- Reflect restored group routing without reopening Kin.
- Preserve browsing position and keep connection controls responsive during refresh.

To update a published preview in Kin, choose Settings > About > Development > Check now. Saved accounts and settings are preserved. Windows may request administrator approval.
