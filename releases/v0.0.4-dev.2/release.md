# Kin client v0.0.4-dev.2

Windows x64 development preview.

- Connect first, then open server selection when you need it.
- Switch servers without reconnecting, with brief visual feedback.
- Improved connection status recovery and server-list handling.
- Refined update progress and retained settings, channel-menu and button-focus fixes.

To update in Kin, choose Settings > About > Development > Check now. Saved accounts and settings are preserved. Windows may request administrator approval.
